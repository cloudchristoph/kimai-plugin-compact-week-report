# Changelog

## Version 0.1.0

Compatibility: requires minimum Kimai 2.61.0

- Initial version
- Compact weekly report: one row per customer/project, columns Monday-Sunday plus totals
- Decimal / h:mm display toggle
- Rounding: nearest or round-up, for quarter/half/full hours
- Every value links to the filtered timesheet detail view
- German and English translations
